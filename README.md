## How to use the collection

1. Start with the domain closest to your task.
2. Open that skill's `SKILL.md` and use it in the Perplexity Computer skill workflow you use for your environment.
3. Combine domain skills when a workflow crosses boundaries. For example, pair `ai-agent-super-skill` with `agent-security-super-skill` when building production agents.
4. Use `token-efficient` as a lightweight companion when you want tighter outputs and lower token usage.
5. Review `DEDUPLICATION_AUDIT.md` for the source-to-repository mapping and duplicate decision.

## Workshop note

These are **super-skills**: intentionally broad playbooks that consolidate related workflows into larger reusable capabilities. They are useful as starting points for experimentation, internal enablement, and adapting to your own agentic workflows.

Before using them in production, review tool names, model names, platform-specific instructions, security assumptions, and any upstream licensing/attribution requirements against your current environment.
